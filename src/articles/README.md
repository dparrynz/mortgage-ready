# Articles

Each article is one Markdown file in `posts/`. The file name becomes the web
address, so `posts/seller-deposit-vs-bank-deposit.md` appears at
`parryfs.com/articles/seller-deposit-vs-bank-deposit`. Keep names short,
lower case, with words joined by hyphens, and matching what people search for.

## The details block

Every file starts with this:

```
---
title: Seller deposit vs bank deposit: why they're not the same
description: One or two sentences, under 155 characters. Shown in Google results.
date: 2026-11-12
guide: deposit-sources
draft: true
---
```

- `guide` (optional) adds a "Related guide" card. One of: `journey`,
  `deposit-sources`, `costs-of-buying`, `kainga-ora`, `glossary`, `borrow-checker`.
- `draft: true` shows the article on preview links only. Change it to
  `draft: false` (or remove the line) to publish it on the live site.

Publishing an article automatically gives it its own page title and
description, a prerendered page for Google, and a place in the sitemap.

## Writing style

- Answer the question in the title within the first two paragraphs.
- `##` for section headings, framed as the questions readers ask.
- Link to Playbook guides with normal links, e.g. `[the journey](/first-home-playbook/journey)`.
- No em dashes or hyphens as mid sentence pauses. Use commas or brackets.
- Informative, not casual. Enough to feel confident, not a textbook.
- Don't tie articles to Auckland.
